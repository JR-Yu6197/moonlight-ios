# 아이폰 듀오용 Moonlight (개인 빌드)

[moonlight-stream/moonlight-ios](https://github.com/moonlight-stream/moonlight-ios)를 아이폰 듀오에 맞게 고친 개인 빌드입니다. 앱스토어 Moonlight와 별개의 앱(`com.jryu6197.moonlight-duo`, 이름 "Moonlight Duo")으로 설치됩니다.

- `iphone-duo` 브랜치: 원본 저장소에 기여할 수 있게 정리한 변경(커밋 5개)만 담았습니다.
- `duo-personal` 브랜치: 위 변경에 개인 서명 설정, 이 문서, 설치 스크립트를 더한 브랜치입니다. 평소에는 이 브랜치로 빌드하세요.

## 바뀐 점

- **안쪽 화면 꽉 채우기**: iOS 27.1 SDK로 빌드하고 UIScene 생명주기를 적용했습니다. 앱스토어 버전처럼 가운데 작은 창으로 뜨지 않습니다. (원본 최신 코드는 Xcode 27로 빌드하면 실행하자마자 종료됩니다.)
- **스트리밍 중 접기/펼치기**: 화면 크기가 바뀌면 영상, 화면 컨트롤러, 안내 문구가 새 크기에 맞게 다시 배치됩니다. 영상 타이밍(디스플레이 링크)도 옮겨 간 화면을 따라갑니다.
- **해상도 Full / Safe Area**: 스트리밍을 시작하는 화면에 맞춰 자동 계산하고, 인코더가 요구하는 짝수로 맞춥니다(안쪽 2852×2006, 바깥 2034×1398). 원본은 설정을 연 화면 기준으로 고정했고, 안쪽 화면에서는 2853×2007(홀수)을 요청했습니다.
- **블루투스 마우스 클릭**: AssistiveTouch가 클릭을 엉뚱한 위치의 터치로 바꿔 보내서 커서가 튀던 문제를 고쳤습니다. 이제 클릭은 PC 커서 위치에서 됩니다.
- **Video Scaling 옵션(Fit / Fill / Stretch)**: PC 화면 비율이 달라도 화면을 꽉 채울 수 있습니다.
- **화면 컨트롤러**: 큰 화면에서는 큰 화면용 배치를 쓰고, 반쯤 접었을 때는 접히는 부분을 피합니다.
- **메인 화면**: 상단 검은 띠 제거, 큰 앱 타일, 화면 크기에 맞춘 PC 목록, 설정 화면이 오른쪽으로 밀리던 문제 수정.

## 설치 / 재설치 (7일마다)

무료 Apple ID로 서명한 앱은 7일이 지나면 실행되지 않습니다. 폰을 Mac에 연결하고 아래 명령을 실행하면 빌드, 설치, 실행까지 한 번에 합니다.

```bash
BuildScripts/install-duo.sh
```

Xcode에서는 Moonlight 스킴과 JRiPhone을 고르고 ▶︎(Run)을 눌러도 됩니다.

## 추천 설정

| 항목 | 값 |
|---|---|
| Resolution | Full |
| Frame Rate | 120 (듀오는 두 화면 모두 120Hz) |
| Video Scaling | PC가 16:9이면 Fill(좌우가 조금 잘림) 또는 Fit |
| Preferred Codec | Auto |

## PC(Apollo) 설정

- **입력 권한**: Apollo는 새로 페어링한 기기에 "보기 + 앱 목록" 권한만 줍니다. 웹 UI의 Device Management에서 기기를 편집해 입력 권한(Controller, Touch, Pen, Mouse, Keyboard)과 Launch를 켜야 터치와 마우스가 동작합니다.
- **검은 띠 없이 쓰기**: PC 해상도를 1.42 비율(예: 2560×1800, 2852×2006)로 맞추면 Fit으로도 화면이 꽉 찹니다. PC가 16:9이면 Apollo가 띠를 영상 안에 넣어 보내므로 Fill이나 Stretch를 쓰세요.

## 블루투스 마우스

iPhone은 AssistiveTouch를 켜야 마우스를 인식합니다.

- 떠다니는 버튼은 설정 → 손쉬운 사용 → 터치 → AssistiveTouch → 포인터 기기의 "메뉴 항상 표시"를 끄면 숨길 수 있습니다.
- 화면의 동그란 포인터와 PC 커서가 따로 보이면, 같은 화면의 포인터 스타일에서 "자동 가리기"를 켜세요. 클릭은 PC 커서 위치에서 됩니다.
- 오른쪽 클릭은 iPhone이 AssistiveTouch 동작으로 가져가서 앱에 전달되지 않습니다.
- 문라이트 설정의 "Citrix X1 Mouse Support"는 Citrix X1 전용이니 꺼 두세요.

## 알려진 제약

- 스트리밍 도중에는 해상도를 바꿀 수 없습니다. 접거나 펴면 같은 해상도의 영상이 새 화면에 맞게 다시 배치됩니다.
- 무료 계정은 앱 서명이 7일마다 만료되고, 기기당 개인 앱 3개까지 설치할 수 있습니다.
